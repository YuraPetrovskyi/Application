# Application — Event Management System

A full-stack Event Management application built with NestJS, React, PostgreSQL, and Docker.

> Detailed setup instructions will be added upon completion.

## Tech Stack

- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS + Redux Toolkit
- **Backend:** NestJS + TypeScript + Prisma + JWT
- **Database:** PostgreSQL
- **DevOps:** Docker + docker-compose
